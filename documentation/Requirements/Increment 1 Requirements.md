# Increment 1 Requirements

## Project description

ISE term project is to develop a standalone desktop application (in C++) for a small super store (or corner shop) so that the store can keep its inventory and record its sales with minimal typing. The application shall allow the cashier to scan a bar code and get the product related information displayed on the screen. This item can be added to an order too and can be a part of the generated bill. The application shall also allow the manager to generate bar code against a product in the store. Further details about the products, files, and their formats will be shared after increment 1. As announced in November 05 lecture, requirements related to increment 1 are as follows:

## Increment 1: Bar Code Generator and Reader

Increment 1 requires the student groups to develop a working version of the C++ application that can do the following:

1. Generate a bar code when provided with a 6-digit number. This bar code should be displayed on the screen and should be saved on disk as an image. The input 6-digit number should start with a non-zero digit.
2. Read a bar code generated in 1 and show the 6 digit number on screen. The bar code can be either uploaded as an image or scanned through laptop camera.

## Notes

- Existing non-standard libraries cannot be used to generate bar codes. Libraries for image processing and filing etc. can be used.
